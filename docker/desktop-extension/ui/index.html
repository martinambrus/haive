Haive

Run Haive locally, then open the app to create your first administrator and connect your AI providers.

Before you start

The Haive worker mounts the Docker socket. It can create and destroy containers and has access equivalent to root on the host. Only run Haive on a machine where you accept this access.

Docker Desktop is required. Windows uses Linux containers; macOS uses CPU Ollama, including Apple Silicon. The published installer selects supported GPU settings on Linux. A GPU is optional.

Install a public release

Install writes a separate Haive Desktop directory in your home folder. Start downloads and runs the release's images. Your existing Haive installs stay separate.

Your data stays local

Stop keeps every data volume. Removing or updating this extension leaves the Haive stack, data volumes, install directory and private operation log in place. Stop Haive before removing the extension if you want it to stop running.

Upgrade Haive from the app's admin console. To remove Haive itself, use the uninstall script in its install directory. Keep that directory and its .env file while keeping data: the encryption key is needed to read stored credentials.

This extension installs public releases. Private channel credentials and module entitlements use the existing installer.
